# Student Performance Data Analysis

## Overview
A multi-tool analysis of a student performance dataset, examining how factors like study hours, attendance, motivation, sleep, family income, and parental education relate to exam scores.

## Tools Used
Excel, Power BI, Tableau, Python (pandas, matplotlib/seaborn)

## Variables Analyzed
Hours studied, exam score, attendance, motivation level, family income, parental education, disability status, internet access, school type, gender, teacher quality

## Key Findings
- **Study time & attendance** are consistently positive predictors of exam score across every tool used
- **Sleep** shows a non-linear relationship — scores peak between 6-9 hours and drop off sharply at 10 hours
- **Parental education** is a stronger predictor of performance than school type (private schools don't guarantee an advantage for students with less-educated parents)
- **Disability status** showed only a minimal achievement gap, suggesting institutional accommodations are largely effective
- **Family income** patterns were counterintuitive — medium-income families showed the highest tutoring usage and parental involvement, not high-income families
- Exam scores followed a roughly **normal distribution centered around 65-70**

## What This Demonstrates
Cross-tool proficiency (Excel, Power BI, Tableau, Python) applied to the same dataset, translating raw variables into decision-relevant insights — e.g., identifying an "optimal sleep window" or flagging that internet access isn't strictly tied to lowest-resource households.
